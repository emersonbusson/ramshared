The RamShared control driver is implemented using the Windows Driver Model (WDM) and raw PIRP handling, not the Kernel-Mode Driver Framework (KMDF). It relies on functions like IoGetCurrentIrpStackLocation and IoCompleteRequest, and does not use KMDF functions like WdfRequestRetrieveInputBuffer. Therefore, the requested task (defensive validation of WDFREQUEST memory descriptors) constitutes an architectural mismatch as WDF is not present in this codebase.
